# Бабочки-частицы — Minecraft Bedrock 1.26.50

Ресурс-пак создаёт летающих бабочек во всём объёме **8×8×8 блоков**. Каждая бабочка собрана из невидимой управляющей частицы и двух привязанных к ней дочерних эмиттеров-крыльев.

## Устройство эффекта

- `snowstorm:two_sprite_area` — невидимый движущийся родитель: выбирает положение, направление и скорость бабочки;
- крылья выводятся серией коротких кадров и наследуют текущую скорость родителя через `particle_with_velocity`;
- ориентация каждого крыла задана явно: в `minecraft:particle_appearance_billboard` секция `direction` с `custom_direction` повторяет вектор взмаха из `emitter_shape_point`;
- каждый кадр состоит ровно из левого и правого крыла;
- оба крыла — жёсткие плоскости постоянного размера, вращающиеся вокруг общей точки;
- нормали крыльев направлены вверх, поэтому бабочки видны сверху;
- анимация каждой бабочки запускается в момент её появления, поэтому фазы взмахов различаются.

## Атлас 128×128

| Спрайт | Назначение | Начало (X, Y) | Размер |
|---|---|---:|---:|
| 1 | левое крыло | `0, 0` | `6×11` px |
| 2 | правое крыло | `7, 0` | `6×11` px |

В комплект включена тестовая пиксельная текстура бабочки. Её можно заменить своей PNG 128×128 с тем же именем и координатами спрайтов.

## Файлы

- `resource_pack/particles/two_sprite_area.particle.json` — управляющий эффект;
- `resource_pack/particles/butterfly_left_wing_0..2.particle.json` — три угла левого крыла;
- `resource_pack/particles/butterfly_right_wing_0..2.particle.json` — три угла правого крыла;
- `resource_pack/textures/particle/two_sprite_area.png` — атлас;
- `two_sprite_area.mcpack` — готовый пакет для импорта.

## Запуск

Импортируйте `two_sprite_area.mcpack`, подключите ресурс-пак к миру и выполните:

```mcfunction
/particle snowstorm:two_sprite_area ~ ~ ~
```

Центр куба будет находиться в точке выполнения команды. `half_dimensions: [4, 4, 4]` задаёт полный объём 8×8×8 блоков.

## Важный нюанс

У крыльев режим билборда — `direction_z`: плоскость крыла ориентируется по вектору `direction`. Если этот вектор не задан явно, игра по умолчанию использует `derive_from_velocity` (порог 0.01), а крылья, заспавненные через `particle_with_velocity`, наследуют скорость родителя (0.18–0.35 м/с) — она выше порога. В итоге нормаль крыла подменяется направлением полёта: крылья разворачиваются ребром к игроку и бабочек не видно, хотя в предпросмотре отдельного крыла (без наследуемой скорости) всё выглядит правильно. Поэтому в каждом wing-файле прописана секция `direction` с `custom_direction` — она фиксирует нормаль по углу взмаха.
